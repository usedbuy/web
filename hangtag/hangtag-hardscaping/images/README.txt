This folder holds this page's graphic assets (photos, logos, etc.).

Right now it's empty on purpose: every graphic on this page — the door
hanger illustration, the logo, the animated results carousel — is inline
SVG and CSS, manipulated live by the page's own JavaScript (it resizes the
ad overlay as visitors change size/quantity), so there are no external
image files for the page to depend on.

If you add real project photos (e.g. to replace the illustrated mockups in
the results section), drop them in here and reference them from index.html
as images/your-file.jpg.
